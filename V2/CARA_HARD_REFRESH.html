🔧 Cara Hard Refresh Browser untuk Fix Display-Weight Freeze

❌ Masalah yang Terjadi:

  • Display-weight freeze di "1.1 g" sebelum Start penimbangan kedua
  • Angka baru berubah setelah klik tombol "Start"
  • Display-weight tidak menampilkan nilai real-time dari scale

✅ Penyebab & Solusi:

Penyebab: Browser masih menggunakan file JavaScript lama (index-f7d163b7.js)

Solusi: Hard refresh browser untuk load file baru (index-234013b9.js)

🚀 Cara 1: Hard Refresh (Paling Mudah)

Tekan tombol berikut BERSAMAAN:

Ctrl + Shift + R

ATAU

Ctrl + F5

Langkah-langkah:
  1. Buka aplikasi di browser (http://localhost:3001)
  2. Tekan Ctrl + Shift + R
  3. TUNGGU 3-5 detik sampai halaman reload sepenuhnya
  4. Halaman akan refresh dengan file JavaScript baru

🧹 Cara 2: Clear Cache & Hard Reload (Jika Cara 1 Gagal)

Untuk Chrome / Edge:

  1. Tekan F12 untuk buka Developer Tools
  2. KLIK KANAN pada tombol Refresh (⟳) di browser
  3. Pilih "Empty Cache and Hard Reload"
  4. TUNGGU sampai reload selesai
  5. Tekan F12 lagi untuk tutup Developer Tools

🔒 Cara 3: Incognito Mode (Paling Pasti)

Gunakan mode Incognito/Private untuk bypass cache sepenuhnya:

  1. Tutup tab aplikasi yang lama
  2. Buka NEW INCOGNITO/PRIVATE WINDOW:
    • Chrome/Edge: Ctrl + Shift + N
    • Firefox: Ctrl + Shift + P
  3. Ketik: http://localhost:3001
  4. Login dan test aplikasi
⚠️ Catatan: Mode Incognito tidak menyimpan cache, jadi PASTI menggunakan file terbaru.

✅ Cara Verifikasi Build Baru Sudah Loaded

Pastikan browser sudah load file JavaScript baru:

  1. Buka Developer Tools: Tekan F12
  2. Klik tab "Network"
  3. Refresh halaman: Tekan F5
  4. Cari file "index-*.js" di list
  5. Pastikan nama file:
    • ✅ BENAR: index-234013b9.js (build baru)
    • ❌ SALAH: index-f7d163b7.js (build lama)

Jika masih load file lama: Gunakan Cara 2 (Clear Cache) atau Cara 3 (Incognito Mode)

🧪 Test Setelah Hard Refresh

Test untuk memastikan freeze sudah fixed:

  1. Login ke aplikasi
  2. Pilih ingredient pertama → Start → Timbang → Complete
  3. Pilih ingredient kedua
  4. LIHAT digital-weight:
    • ✅ BENAR: Menampilkan nilai real-time (misalnya "0.5 g", "0.0 g")
    • ❌ SALAH: Freeze di "1.1 g"
  5. Letakkan beban di scale (JANGAN klik Start dulu)
  6. LIHAT digital-weight:
    • ✅ BENAR: Angka update TANPA klik Start
    • ❌ SALAH: Angka tidak update sampai klik Start

❓ Troubleshooting

Q: Sudah hard refresh tapi masih freeze?

A: Coba langkah berikut secara berurutan:

  1. Clear browser cache (Cara 2)
  2. Close semua tab browser
  3. Buka ulang browser
  4. Gunakan Incognito mode (Cara 3)

Q: Bagaimana tau sudah load build baru?

A: Check di Developer Tools → Network → File harus index-234013b9.js

Q: Incognito mode juga masih freeze?

A: Berarti ada masalah lain. Check:

  • Server masih running? (Check terminal)
  • WebSocket connected? (Check console browser)
  • Ada error di console?
