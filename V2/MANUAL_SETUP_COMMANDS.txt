================================================================
TROUBLESHOOTING
================================================================

Error: psql is not recognized
  → Install PostgreSQL atau tambahkan ke PATH

Error: connection failed
  → PostgreSQL service tidak running
  → Buka services.msc, start postgresql service

Error: password authentication failed
  → Password bukan Admin123
  → Ubah: set PGPASSWORD=your_password

Error: No such file or directory
  → File database tidak ada
  → Cek lokasi dengan: dir database\
  → Atau gunakan path parent: ..\database\

Error: database already exists
  → Normal, DROP DATABASE dulu atau skip CREATE
