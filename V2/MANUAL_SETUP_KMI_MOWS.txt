================================================================
TROUBLESHOOTING
================================================================
1. Error "password authentication failed"
   -> Set PGPASSWORD dengan password PostgreSQL yang benar

2. Error "database already exists"
   -> Database sudah ada, bisa skip atau drop dulu

3. Error "user already exists"
   -> User sudah ada, bisa skip atau update password:
      psql -U postgres -c "ALTER USER admin WITH PASSWORD 'admin123';"

4. Error "permission denied"
   -> Pastikan menjalankan sebagai superuser postgres
   -> Pastikan privileges sudah diberikan

5. File tidak ditemukan
   -> Pastikan berada di folder V2
   -> Cek apakah folder database ada
   -> Gunakan path lengkap jika perlu
