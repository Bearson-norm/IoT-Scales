  SOLUSI PRINTER - AUTO-DETECT DAN FALLBACK KE EPSON
═══════════════════════════════════════════════════════════════

MASALAH:
  Konfigurasi hanya bisa mendapatkan printer Epson, 
  bukan Xprinter XP-420B

SOLUSI YANG DITERAPKAN:
  ✅ Auto-detect printer saat server startup
  ✅ Filter printer offline dan "Copy X"
  ✅ Filter virtual printer (PDF, OneNote, dll)
  ✅ Prioritas printer online dan asli
  ✅ Fallback otomatis ke Epson jika XP-420B tidak ada
  ✅ Simpan konfigurasi printer secara otomatis

CARA MENGGUNAKAN:
  1. Restart server
  2. Server akan otomatis detect printer Epson Anda
  3. Label akan otomatis cetak ke printer Epson
  
  TIDAK PERLU KONFIGURASI MANUAL!

YANG AKAN TERLIHAT DI LOG:
  🔍 Auto-detecting thermal printers...
  ✅ Auto-detected printer: EPSON L3210 Series
  💾 Updated printer config with detected printer
  
  Saat print:
  ⚠️  Configured printer "Xprinter XP-420B" not found
  📌 Fallback to: "EPSON L3210 Series"
  ✅ Method 1 SUCCESS: Receipt sent

FILE YANG DIUPDATE:
  - server.js (auto-detect dan fallback logic)
  
FILE KONFIGURASI OTOMATIS:
  - printer_config.json (akan dibuat otomatis)

DOKUMENTASI:
  - SOLUSI_PRINTER_EPSON.md (detail lengkap Bahasa Indonesia)
  - PRINTER_AUTO_DETECT_GUIDE.md (technical guide English)

CATATAN:
  - Printer Epson bisa digunakan, tapi bukan thermal printer
  - Hasil print mungkin berbeda dari thermal label
  - Untuk hasil optimal, gunakan printer thermal (XP-420B)
