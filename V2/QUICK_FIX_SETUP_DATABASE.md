# 🚀 Quick Fix: setup-database.bat Langsung Tertutup

## ⚡ Solusi Super Cepat (1 Menit)

### Jangan jalankan ini:
```
❌ setup-database.bat  (langsung tertutup)
```

### Jalankan ini sebagai gantinya:
```
✅ setup-database-debug.bat  (window tetap terbuka)
```

**SELESAI!** Sekarang Anda bisa lihat error dengan jelas! 👀

---

## 🎯 Atau Gunakan Command Prompt (2 Menit)

### 1. Buka Command Prompt
- Tekan `Windows Key`
- Ketik `cmd`
- Enter

### 2. Pindah ke Folder V2
```cmd
cd C:\path\to\your\V2\folder
```
*Ubah path sesuai lokasi folder Anda!*

### 3. Jalankan Setup
```cmd
setup-database.bat
```

**Sekarang Anda bisa LIHAT ERROR!** 🎉

---

## 📋 Checklist Cepat

Sebelum setup, pastikan:
- [ ] PostgreSQL sudah install → `psql --version`
- [ ] PostgreSQL service running → cek di `services.msc`
- [ ] Password PostgreSQL = `Admin123` (atau ubah di script)

**Belum pasti?** Jalankan ini untuk cek semua:
```cmd
check-requirements.bat
```
